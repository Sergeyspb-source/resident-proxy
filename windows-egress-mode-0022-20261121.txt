Функциональность
«По маршруту компьютера» сохраняет обычную исходящую маршрутизацию.
«Только прямой выход» подтверждает физический интерфейс Ethernet/Wi-Fi,
выбранный Windows для проверенного IP назначения, и привязывает к нему
сокет. Туннель, неподтверждённый интерфейс или смена маршрута закрывают
запрос. Действующие сокеты проверяются раз в секунду. Смена режима
сохраняется до применения и закрывает активные и ожидающие соединения.
Режим хранится рядом с локальным состоянием узла, у старых установок
по умолчанию остаётся системный маршрут.

Настройка доступна в «Настройки → Исходящий маршрут». Владелец видит
последнее назначение, тип маршрута, интерфейс, итог и время. Клиент
Aspire получает итог для своего ключа по внутреннему TLS. После
«Проверить связь» условия обновляются, если приглашение загружено.
Имена интерфейсов доступны только локальной панели владельца.
Данные относятся к последнему запросу, а видимый публичный адрес
проверяется отдельно. Физический маршрут не определяет тип публичного
IP; возможны ограничения сторонних фильтров Windows и оборудования.
Строгий режим рассчитан на Windows. Режим системы работает на Linux.
